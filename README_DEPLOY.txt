LUMI TV — GitHub Pages
1. Envie index.html, assets/ e status.json para a raiz do repositório.
2. GitHub > Settings > Pages > Deploy from a branch > main > /(root).
3. Configure o domínio personalizado: tv.uselumisoft.tech
4. No Cloudflare, crie o CNAME 'tv' apontando para <SEU-USUARIO>.github.io.
5. Mantenha DNS only durante a validação inicial do GitHub Pages.
6. playlist.m3u e epg.xml serão adicionados quando os artefatos reais estiverem validados.
